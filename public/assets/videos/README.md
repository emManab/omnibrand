# Calcuttapress Video Assets Directory

You can place your real `.mp4` / `.webm` video files directly in this directory or subfolders.
The application will automatically detect and play them, and fall back to photography if the video isn't added yet!

## Recommended Video Locations

### 1. Hero Offer Videos (`public/assets/videos/`)
- `hero-festival-savings.mp4` -> Plays in the festival hero banner
- `hero-welcome.mp4` -> Plays in the welcome offer hero banner
- `hero-winterwear.mp4` -> Plays in the winterwear offer hero banner

### 2. Category Videos (`public/assets/videos/categories/`)
- `visiting-cards.mp4` -> Visiting Cards category tile
- `polo-t-shirts.mp4` -> Custom Polo T-shirts category tile
- `dress-shirts.mp4` -> Custom Dress Shirts category tile
- `t-shirts.mp4` -> Custom T-shirts category tile
- `winter-wear.mp4` -> Custom Winter Wear category tile
- `stamps-ink.mp4` -> Custom Stamps & Ink category tile
- `signs-posters.mp4` -> Signs & Posters category tile
- `marketing-materials.mp4` -> Marketing Materials category tile
- `labels-stickers.mp4` -> Labels & Stickers category tile
- `packaging.mp4` -> Packaging category tile
- `stationery.mp4` -> Custom Stationery category tile
- `photo-gifts.mp4` -> Photo Gifts category tile

### 3. Promotional Banner Videos (`public/assets/videos/banners/`)
- `promo-business-cards.mp4` -> Business cards promo card
- `promo-apparel.mp4` -> Custom apparel promo card
- `promo-stickers.mp4` -> Stickers & labels promo card
- `promo-packaging.mp4` -> Packaging & boxes promo card

### Tip
- For best web performance, use 720p or 1080p MP4 files with H.264 video codec, optimized for web streaming (faststart / web-optimized).
- Videos play muted and loop automatically.
